# 🎯 Personal Improvement Tracker

A clean, dark-themed Java desktop application designed to streamline personal goal setting, daily habit tracking, and productivity logging.

---

## ✨ Features

- **📊 Dashboard Overview**: Visual metrics for Total Goals, In Progress, Completed, and Average Progress percentages.
- **⏱️ Focus Analytics**: Weekly focus time bar chart and a daily focus timer/logger.
- **🏷️ Goal Categorization**: Organize goals by category (*Study*, *Health*, *Finance*, etc.) with status tags.
- **➕ Easy Goal Creation**: Add target amounts, track time in minutes, and toggle deadline target dates.
- **🗂️ Progress Logs**: Individual goal cards equipped with quick actions to log time (`+ Log`), edit details, view history, and mark done.

---

## 🛠️ Tech Stack

- **Language**: Java
- **GUI Framework**: JavaFX / Swing
- **UI Style**: Modern Dark Theme
